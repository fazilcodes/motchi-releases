# Motchi releases

Installers and update files for **Motchi**, a calm notch for your Windows screen: https://motchi.xyz

- Download Motchi from **https://motchi.xyz** or the **Microsoft Store**.
- Every installer here is signed with Motchi's release key (`.sig`), and the app refuses updates that don't match.
- The app's source code is private; this repository only holds release files.
